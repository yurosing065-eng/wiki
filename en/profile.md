# Profile menu

The profile menu contains basic player information and useful account sections.

Open it by selecting **Profile** in the game menu.

![CosmoLand profile menu](/profile-menu.png)

Available sections include:

- **Player reviews** — reviews about you;
- **Social networks** — linked profile links;
- **Game statistics** — your main stats and achievements;
- **Profile settings** — personal profile options;
- **Back to menu** — return to the previous screen.
