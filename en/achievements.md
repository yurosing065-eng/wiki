# Custom achievements

CosmoLand has its own space-themed achievement system. Explore new worlds, survive dangerous places and complete entries in your journal.

### First launch

![First launch achievement](/achievement-first-launch.png)

## Space travel

| Achievement | How to unlock |
| --- | --- |
| First launch | Join CosmoLand for the first time |
| Moonlight | Visit the Moon |
| Red horizon | Visit Mars |
| Home again | Return to the main world |
| Between worlds | Visit every CosmoLand world |
| Little space home | Place a supply container |
| Surface scan | Collect a rock sample |
| Cosmic builder | Place a block in a new world |
| Zero gravity | Jump above the clouds |
| Star cartographer | Explore 10,000 blocks from home |
| Signal lost | Become alone in an unexplored world |
| Oxygen reserve | Spend a night away from home |
